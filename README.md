# Lega Sealed Pavia – Reality Fracture

Sito statico per la lega sealed di Magic: The Gathering tra amici a Pavia:
8 giocatori, 5 serate, classifica, abbinamenti svizzeri e pool di carte di ogni giocatore.

Costruito con [Astro](https://astro.build) e pubblicato su GitHub Pages.

## Comandi principali

| Comando           | Cosa fa                                                      |
| :---------------- | :----------------------------------------------------------- |
| `npm install`     | Installa le dipendenze (solo la prima volta o dopo modifiche) |
| `npm run dev`     | Avvia il sito in locale su `http://localhost:4321`            |
| `npm run build`   | Genera il sito finale nella cartella `dist/`                  |
| `npm run preview` | Mostra in locale il sito generato da `build`                  |

Requisito: **Node.js 24** o superiore.
